one-emoji-smile is a tiny program that writes exactly one emoji to a file: 🫶, the heart-hands gesture — two hands shaping a heart, offered to whoever sees it.

One character, no words, no caption. The choice is deliberate: a shaped heart is an act, something offered to a stranger, while a smiling face only shows a mood. It reads the same way at any age and in any place — kindness, offered openly, with no joke, no irony and nothing asked in return. Of the faces and symbols considered, the heart hands won because they aim directly at warming the reader, instead of merely looking cheerful.

## Run it

```sh
python3 main.py
```

It writes the emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Standard library only, no network access; the same bytes, byte for byte, on every run.
